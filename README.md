# Hwang-mijeoung

Research notes, numerical tests and verification models for the Riemann Hypothesis — *The Hwang Mijeoung Model*.

Author: Hwang Mijeoung (황미정), independent researcher. AI systems assisted with discussion, computation and cross-checking; the pictures and questions are the author's.

This is not a proof of the Riemann Hypothesis. Every claim in the documents carries a tag (established / computed / model / metaphor / open), and the Riemann Hypothesis remains open.
